# FERRAMENTA DE PDF
A ferramneta pdf tools utiliza a blbioteca python "pypdf", para a manipulação de arquivos PDFs, e streamlit para criar uma interface web disponível na rede local com o comando:
'streamlit run pdf_toolkit_app.py'

## funcionalidades
- Juntar múltiplos PDFs em um único arquivo
- Reorganizar (reordenar) as páginas de um PDF
- Remover páginas específicas
- Baixar o resultado final
